# 제주 행사 questionnaire timing / unknown policy

## 목적

질문 수를 억지로 줄이지 않는다. 사용자가 이미 보았거나 `잘 모르겠어요`로 답한 사실을 같은 세션에서 다른 문구로 다시 묻지 않고, 모르는 사실은 판정에서 계속 `UNKNOWN`으로 유지한다.

## 감사 결과

### 변경 전

| 영역 | 기본 질문 | 뒤늦게 나타날 수 있던 질문 | 문제 |
|---|---|---|---|
| 자산 | 본인/세대 총자산, 부모 총자산 | 세대 차량가액, 본인 자산 | 차량가액은 7개 조합이 요구하는 core fact인데 adaptive에서 처음 등장했다. |
| 부모 정보 | 부모 총자산 숫자 입력 | 부모 소득·차량 | 부모가 없거나 연락이 어려운 경우와 단순 미입력을 구분하지 못했다. |
| 당첨 제한 | 포괄적인 당첨 이력 한 문항 | Samdo의 특별공급 이력·재당첨 제한·5년 이력 | “당첨 있음”을 세 제한으로 확정할 수 없고, 다른 문구로 재확인될 수 있었다. |
| 자녀 | 출생한 자녀 수와 생년월일 | Samdo 태아·입양·출산완화 확인 | 0명 답이 태아·입양 없음이라는 뜻은 아니어서 뒤에서 evidence fact가 남았다. |
| unknown | 예/아니요 일부만 `null + answered` | 숫자·날짜 질문 | 비움과 명시적 모름이 구분되지 않았다. |

| timing | 질문/fact | 정책 |

| 청약통장 | 종류, 가입일, 인정 납입횟수·금액, 1순위 | 서로 다른 fact로 유지하며 모름을 0/false로 바꾸지 않는다. |

## 공통 필수 질문

다수 공고 또는 Samdo 자동추천 전반에서 후보·자격·공급단계에 직접 쓰여 첫 분석 전에 받는 항목이다.

- 가구 형태
- 신청자 생년월일
- 제주 거주 및 장기 해외체류
- 태아·입양 예정 상태
- 신청자 월소득
- 현재 세대 무주택
- 과거 주택소유
- 특별공급 당첨 이력
- 재당첨/부적격 제한
- 최근 5년 세대 당첨 이력
- 본인/세대 총자산
- 세대 차량 최고가액
- 청약통장 종류

기존 graph에서 core인데 adaptive에만 있던 `household.maxVehicleValueKrw`는 이제 기본 finance 단계에 있다. 따라서 공통 필수 fact가 최초 분석 뒤 처음 나타나는 사례는 0건이다.

## 조건부 adaptive 질문

아래 항목은 특정 공급유형이 아직 살아 있고 해당 Rule Package가 요구할 때만 묻는다.

- 신청 가능 거주자 자격
- 해당 매입임대의 현재 계약/거주 여부
- 대학생·입학/복학 예정 또는 취업준비생 상태
- 복지급여/지원 자격
- 소득 있는 업무 종사기간
- 신청자 본인 자산 보완
- 부모 월소득·부모 차량가액

이미 `INELIGIBLE`인 listing/supplyType은 질문 소비자에서 제외한다. 하나의 fact가 여러 조합에서 쓰이면 질문 ID 하나로 합친다.

## 서류/증빙형 질문

장애 가점, 공식 우선순위 증빙, 임차료 부담률, 부모 무주택 등은 행사 답변만으로 확정하지 않는다. 질문을 생략하거나 모름으로 답하면 `EVIDENCE_REQUIRED`/`확인 필요`를 유지한다.

## 명시적 모름을 허용하는 항목

- 신청자·세대 소득
- 본인/세대 총자산과 차량가액
- 부모 자산·소득·차량가액
- 청약통장 가입일·납입횟수·인정금액·1순위
- 특별공급 이력·재당첨 제한·5년 내 당첨 이력
- 과거 주택소유
- 장기 해외체류
- 태아·입양 예정 상태
- 혼인신고일·자녀 생년월일

### 사용자 표시 문구와 domain mapping

표시 문구는 질문 의미에 맞게 다르지만, 아래 선택은 모두 값을 채우지 않고 `answerStates[fact] = DOES_NOT_KNOW`로 저장한다.

| 질문 성격 | 화면 문구 | 적용 예 |
|---|---|---|
| 금액·인원·횟수 | `정확히 몰라요` | 본인/세대/부모 소득·자산, 차량가액, 세대원·자녀 수, 납입횟수·금액 |
| 날짜 | `정확한 날짜를 몰라요` | 혼인신고일, 자녀 생년월일, 청약통장 가입일 |
| 기간 | `정확한 기간을 몰라요` | 제주 연속 거주기간, 소득세 납부기간, 근로기간 |
| 과거 이력 | `기억나지 않아요` | 과거 주택소유, 특별공급/최근 당첨 이력, 장기 해외체류 |
| 증명·현재 상태 | `확인해 봐야 해요` | 재당첨 제한, 태아·입양, 통장 종류·1순위, 혼인/예비혼인 상태 |

부모 자산은 `금액을 알고 있어요 / 정확히 몰라요 / 연락·확인이 어려워요 / 부모님이 안 계세요`를 분리한다. 뒤의 세 선택은 모두 부모 자산 금액을 만들지 않고 결과의 확인 필요 상태를 유지한다. 사용자가 명시적 모름을 선택하면 `괜찮아요. 결과에서 확인이 필요한 항목으로 표시할게요.` 안내를 보여 준다.

## 재질문 방지

`answerStates`는 질문별로 `ANSWERED`와 `DOES_NOT_KNOW`를 분리한다. 사용자가 `잘 모르겠어요`를 누르거나 기본 단계를 비운 채 다음으로 이동하면 해당 질문은 `DOES_NOT_KNOW`가 된다.

fact-level alias 표는 기본 질문과 adaptive/Samdo 질문이 같은 사실을 가리키는지 판별한다. 값이 있거나 명시적 모름으로 처리된 fact는 같은 세션에서 다른 문구로 재생성하지 않는다. domain 값은 그대로 unknown이므로 ELIGIBLE/INELIGIBLE로 낙관·비관 변환되지 않는다.

### 명시적 모름 QA persona

| persona | 보존하는 상태 | 같은 fact 재질문 |
|---|---|---:|
| 부모 자산 모름 | `EVIDENCE_REQUIRED` 또는 `CONDITIONAL` | 0 |
| 부모 없음 | 부모 자산을 0원으로 만들지 않고 확인 필요 | 0 |
| 부모 연락 곤란 | 부모 자산을 0원으로 만들지 않고 확인 필요 | 0 |
| 청약통장 납입횟수 모름 | 횟수 미확정·확인 필요 | 0 |
| 과거 당첨이력 기억 안 남 | 제한 이력 미확정·확인 필요 | 0 |
| 해외체류 여부 모름 | 거주 요건 미확정·확인 필요 | 0 |
| 자녀 생년월일 일부 모름 | 출산/연령 조건 미확정·확인 필요 | 0 |

## 정당하게 뒤에서 나타나는 질문

조건부 공급이 1차 평가 후에도 살아 있을 때만 필요한 학업상태, 복지자격, 현재 임대 거주, 부모 소득·차량, 근로기간은 adaptive에 남는다. 이는 사용자 가구형태와 1차 자격에 따라 필요 여부가 달라 기본 설문에 일괄 노출하지 않는 항목이다.
