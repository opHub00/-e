# Peer Benchmark V1 공식 근거 조사

조사일: 2026-09-09 (KST)

## 확인된 공식 공개 범위

- [공공데이터포털 — 한국부동산원 청약홈 청약통장 통계 조회 서비스](https://www.data.go.kr/data/15114369/openapi.do)
  - 제공기관: 한국부동산원
  - 등록일: 2023-06-09
  - 수정일: 2023-06-16
  - 공개 범위: 전체 가입현황, 통장별 가입현황, 가입기간별 가입현황
  - 포털 metadata의 공간범위와 시간범위는 별도 값이 기재돼 있지 않다.
- [한국부동산원 기술문서 안내](https://www.reb.or.kr/reb/na/ntt/selectNttInfo.do?mi=10251&bbsId=1268&nttSn=87460)
  - 청약홈 청약통장 통계 조회 Open API 기술문서와 지역코드 자료를 제공한다.
- 청약Home의 `청약일정 및 통계 → 청약통장 통계` 메뉴도 전체·통장별·가입기간별 현황을 구분한다.
- KOSIS는 공식 통계 Open API를 제공하지만, 이번 조사에서 ApplicantProfile과 직접 비교할 수 있는 연령·지역·가입기간 결합 청약통장 표는 확인하지 못했다.

## V1 적용 판단

- 공개 범위와 기관·조사일 metadata는 `official` layer에 표시한다.
- 현재 확보한 자료만으로 연령대 평균, 지역·연령 결합 평균, 당첨자 평균은 만들지 않는다.
- 공식 수치와 완판e 내부 준비 확인 기준을 한 지표로 합치지 않는다.
- V1은 공식 숫자를 snapshot으로 복제하거나 실시간 조회하지 않는다. 따라서 오래된 숫자를 최신값처럼 보여주는 위험이 없다.
- 향후 공식 숫자를 표시할 때는 서버 adapter, 조회 기준일, 지역·통장종류·가입기간 범위, 원문 링크를 함께 저장해야 한다.
