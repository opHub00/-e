# 삼도이동 VER1.7 검토본 규칙 명세

## 출처와 검증 범위

- 파일: `(VER1.7_부동산원 제출용_공통) 삼도이동 1지구 토지임대부 분양주택 입주자모집공고문.hwp`
- 크기: 4,534,784 bytes. SHA-256: `bd67d7ee6c9b9dbbe043f9c966679c791185ba0f21ae80050a33a489112e8763`.
- 사용자 제공 검토본. 공고일 기재값 `2026-09-14`. **DRAFT_SOURCE_VERIFIED이며 공식 승인·최종 게시본을 뜻하지 않는다.**
- `scripts/extract-hwp-text.py`가 HWP5 OLE BodyText를 압축 해제하고 문단 텍스트 4,115개를 추출한다. 필드/메모 헤더도 추출했다.
- 아래 `P숫자`는 추출 JSON의 **0부터 시작하는 문단 인덱스**다. 페이지 번호가 아니다. evidence에는 원문 SHA, stream, 압축 해제 스트림 record offset을 보존한다. 모든 pageNumber는 null.
- 표의 병합 셀을 평탄화한 텍스트를 문단 순서와 반복 표로 대조했다. 시각적 원문 렌더링/최종 법적 검수는 별도로 필요하다.
- 파서 근거: [한컴 HWP5 공개 사양](https://cdn.hancom.com/link/docs/%ED%95%9C%EA%B8%80%EB%AC%B8%EC%84%9C%ED%8C%8C%EC%9D%BC%ED%98%95%EC%8B%9D_5.0_revision1.2.pdf)의 본문 레코드·제어문자·메모 리스트 구조.

## 공통 조건

- 제주 거주: P1887/P2031/P2292. 장기복무군인 예외가 있는 사람은 특례 입력으로 검수한다.
- 성년: P268의 만19세 이상. 신혼/생애최초 미성년 신청자는 P1110의 세대주 예외를 자동 확정하지 않고 추가 확인한다. 미성년 자녀는 만19세 미만으로 집계한다.
- P268은 “1년 이상”이라고 하면서 시작일을 `2026.09.14. 이전`으로 적었다. P19/P211의 `2025.09.14. 이전`과 다르므로 지역우선 배정을 확정하지 않는 추가 근거다.
- 표2(P1079–1099): 1년 이상 해당지역 100%, 1년 미만 기타지역 0%, 미달 물량은 기타지역. 이 수치는 전사하되 수정 메모 때문에 배정을 확정하지 않는다.
- 해외 체류(P216–219/P1080): 계속 90일 초과, 연간 183일 초과, 입국 후 7일 이내 동일국가 재출국 합산 및 생업 예외 등이 있다. 이력이 없다고 확인한 경우만 연속거주 계산. 이력이 있거나 모르면 추가 확인. 단기 체류도 자동 탈락 처리하지 않는다.
- 통장 종류: 종합저축/청약저축, 6개월/6회. 통장 보유 profile 재사용 + 종류/정확한 날짜/인정횟수 추가 입력.
- 특별공급 이력, 부적격/재당첨 제한: P276/P2021/P2022/P2276. 특례·일정에 따라 검수가 필요하므로 제한/이력 있음은 REVIEW 처리.
- 특례 있음, 출산가구 완화 가능성 또는 태아/입양 적용: 자동 승인·자동 탈락 대신 NEEDS_MORE_INFORMATION.
- 필요서류: 주민등록표등본·초본, 출입국 사실증명, 청약통장 순위확인서, 혼인·가족관계 증명, 자산 보유 사실확인, 금융정보 제공 동의, 소득금액증명, 표14 소득세 납부 입증서류. 최종 제출 목록과 발급 대상은 원문 심사 기준을 확인한다.

### 날짜 계산

`dateFacts.ts`의 noHomeDuration은 P2216/P2254의 시작일을 구현한다.

1. 만30세 도달일. 30세 전 혼인이 있으면 **최초 혼인신고일**.
2. 세대의 주택처분일 중 가장 최근 날짜보다 앞서 시작하지 않는다.
3. 이혼 후에도 최초 혼인일을 유지한다. 혼인 이력·처분일 누락은 미상.
4. 30세 미만 혼인이력 없음은 기간0개월이지만 “산정 대상 아님”으로 구분하여 0점. 적용 대상의 0개월(한 달 미만)은1점.
5. 혼인2/7년 자격 경계는 일 단위 비교. `24개월`로 버림하여 2년+1일을 잘못 포함하지 않는다.

원문 P2255–2260의 여섯 사례(4년,1년,5년,2년,6년,0년)를 모두 테스트한다.
배우자 혼인 전 소유·처분 제외(P2261), 재혼 합산(P2267), 입양/재혼 자녀 등재 요건은 특례 검수로 남긴다.

## 재현과 배포 경계

```powershell
python scripts/extract-hwp-text.py "원문.hwp" .cache/samdo-hwp.json
python scripts/build-samdo-draft-package.py
npm run assessment:rules -- validate data/assessment-rules/samdo-2026-v1.7.json
npm run test:assessment-samdo-db
```

원문 SHA가 다르면 builder/DB 검증이 실패한다. 원문 파일은 Git 및 앱 번들에서 제외하고 private Storage 대상으로 유지한다.
JSON package는 DB import용이다. UI는 이를 import하지 않고 기존 DatabaseRuleRepository만 사용한다.
현재 승인/활성화 실행은 **격리 PGlite** 안에서만 수행한다. local QA HTTP bridge는 실제 SQL anon read를 전달하되 Supabase/PostgREST/Storage 서비스 자체를 대체 검증하지 않는다.
운영 등록에는 기존 import CLI의 private upload/hash 확인, 실제 Supabase staging 검수 및 권한 점검을 거쳐야 한다.
